# Status history

Archive of completed status entries from `docs/status/current.md`.

When an open-work item in `current.md` is finished, move its entry here in the
same commit that lands the work, prefixed with the completion date:

```
## 2026-11-13 — p20 paged attention (completed)
<entry text>
```

`current.md` stays bounded; this directory keeps the full record.
