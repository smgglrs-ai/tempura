The mathematics that tempura kernels implement, connected to the Rust source and the Kani proofs that verify them.

Each page covers one kernel family: the theory with proper notation, numerical considerations, a worked example, and links to the implementation in `kernels/src/`.

For the progressive tutorial (starting from vectors and building up to full inference), see the [Learn track](/docs/learn/).
